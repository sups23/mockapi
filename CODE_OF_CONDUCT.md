# Code of Conduct

## Our Standard

We aim to keep Seedbox welcoming, constructive, and focused on the work.
Participants must treat others with respect and should assume good intent
while discussing technical decisions.

Unacceptable behavior includes harassment, discrimination, personal attacks,
deliberate disruption, publishing private information, and any other conduct
that would be inappropriate in a professional engineering community.

## Enforcement

Project maintainers may remove comments, close discussions, or restrict
participation when this standard is violated. Report concerns privately through
the process in `SECURITY.md` or by contacting the repository owner on GitHub.
